# Native processing API (self-host only, v0)

**Transport:** same-origin HTTPS through Caddy. Development: HTTP on
localhost:8080. API base: /api/native. The service is not exposed
on its own publicly reachable port. This is a first-party, anonymous
session API, not an authenticated external developer API.

- GET /health — open codec registry, file/duration/resource limits.
- POST /jobs — JSON {"filename":"clip.mov","bytes":123456} creates a job.
  Establishes a random, opaque HttpOnly SameSite=Strict cookie (Secure
  under HTTPS). Response 201 includes a random job ID.
- PUT /jobs/:id/input — application/octet-stream with exact Content-Length
  equal to the declared upload bytes. Raw streaming body; 200 on complete.
- POST /jobs/:id/start — JSON {"format":"mp4","quality":"balanced",
  "height":720}. Other formats: mov, webm, mp3, wav, flac, gif.
  Quality: high/balanced/small. Height: null/480/720/1080.
  The server chooses actual FFmpeg settings; user flags are rejected.
- GET /jobs/:id — scoped job state, measured progress, output descriptors.
- GET /jobs/:id/download — scoped attachment stream after successful
  FFprobe verification. No secret token in a query string.
- DELETE /jobs/:id — cancel the job, abort subprocess and delete media.

Stages: awaiting-upload, uploading, uploaded, queued, probing, processing,
verifying, ready, failed, cancelled. Processing percentages are reported
only from FFmpeg progress timestamps and capped at 99 until final
verification. Queue and probe stages can be indeterminate.

Security: requests with foreign Origin are rejected, cookies are
restricted to the API path, IDs are cryptographically random,
cross-session job reads return 404, uploaded paths are generated by
the server, and the worker runs nonroot in an isolated Docker network.

Operational limitations: one instance, RAM-backed metadata and queue,
ephemeral storage, no resumable uploads, and no guarantee of jobs
surviving an instance restart. Public deployments require additional
identity, abuse and billing controls. These limitations are part of
the v0 contract and MUST NOT be hidden in product copy.

The native service is Apache-2.0 as source code; binary FFmpeg and codecs
have their own license terms. See SELF_HOST.md.
